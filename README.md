## İctimai URL-lər

Bu qovluq ayrıca, **public** GitHub repository kimi yayımlana bilər. Nümunə:

```text
https://github.com/YOUR_GITHUB_USERNAME/rentcarbaku-legal/blob/main/PRIVACY_POLICY.md
https://github.com/YOUR_GITHUB_USERNAME/rentcarbaku-legal/blob/main/TERMS_OF_SERVICE.md
https://github.com/YOUR_GITHUB_USERNAME/rentcarbaku-legal/blob/main/SUPPORT.md
```

Repository-yə giriş tələb olunmamalıdır. Linkləri GitHub hesabından çıxış edilmiş gizli brauzer pəncərəsində yoxlayın.

Tətbiqdə istifadə edilən URL-lər aşağıdakı fayllarda eyni ünvanlara dəyişdirilməlidir:

```text
rentcarbaku-app/src/rentcar/publishing/app.config.json
rentcarbaku-app/src/rentcar/rentcar.settings.js
```

Hüquqi mətn və ya əlaqə məlumatı dəyişdirildikdə sənədlərdəki “Son yenilənmə” tarixi də yenilənməlidir.
