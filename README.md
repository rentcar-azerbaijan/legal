## GitHub Pages setup

In the repository, open **Settings → Pages**, choose **Deploy from a branch**, select the default branch and `/ (root)`, then save.

Legal content or contact changes must be applied to both the Markdown source and corresponding public HTML page. Update the document's “Son yenilənmə” date when its legal substance changes.
